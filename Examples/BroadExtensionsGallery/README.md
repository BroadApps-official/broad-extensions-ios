# BroadExtensionsGallery

Standalone iPhone sandbox для четырёх capabilities модуля:

- hex colors;
- keyboard dismiss;
- scoped interactive swipe-back;
- правила custom-font registration.

```bash
bash Scripts/generate_gallery.sh
open Examples/BroadExtensionsGallery/BroadExtensionsGallery.xcodeproj
```

Gallery использует local package path и не является обязательной зависимостью
host app.
