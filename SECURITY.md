# Security

Не публикуйте security issue с ключами, credentials, персональными данными или
exploit details. Передайте такое сообщение владельцам BroadApps приватным
организационным каналом.

BroadExtensions не должен хранить network credentials, payment data, analytics
payloads или user identity. Public pull requests автоматически проверяются на
типовые secret patterns.
